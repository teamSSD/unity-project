# ADR-003: 정책 기반 실제 플레이 매크로

상태: 승인됨
일자: 2026-09-07

## 결정

기존 시뮬레이션의 플레이 정책을 별도 복제하지 않는다. 정책이 요구하는 관측값과 반환하는 결정을 공용 계약으로 추출하고, 다음 두 실행기가 같은 정책 계약을 사용한다.

- Editor simulation: 빠른 경제/밸런스 탐색
- WebGL playtest macro: 실제 브라우저 입력으로 게임을 진행하는 통합 검증

WebGL 쪽은 게임 상태 조회, UI 대상의 화면 좌표 조회, 테스트 프로필 준비만 제공한다. 메뉴 선택, 구매, 이동, 버튼 클릭, 요리, 페이즈 종료는 매크로가 실제 마우스·키보드 입력으로 실행한다.

## 최초 캠페인

`Baseline` 정책으로 튜토리얼 완료 프로필에서 7일을 운영한다. 각 일차에 메뉴, 구매, 액션, 주문/퀘스트, 정산, 저장 후 새로고침을 기록한다. 그 뒤 `Cautious`, `AdaptiveSide`를 같은 driver로 교체 실행한다.

## 구현 현황

- 완료: `BaselinePolicy`의 7일 결정 로그 export, 고정 시드·튜토리얼 완료 테스트 프로필, UI/월드 목적지 관측, 정책의 첫 메뉴 결정을 실제 키보드·마우스 입력으로 실행하는 파일럿.
- 미완료: 구매·요리·정산·저장 복구까지 포함한 7일 campaign driver와 일차별 기대값 비교.
- 차단 이슈: 현재 WebGL Chromium 실행에서 UI 효과음 FSB decode 오류가 발생한다. 실제 입력 파일럿은 메뉴 선택 상태까지 도달하지만, 오류 없는 통과 기준은 이 문제를 해결하기 전에는 만족하지 않는다.

## 통과 기준

- 정책의 결정과 실제 실행된 입력이 같은 action log에 남는다.
- 일차별 돈·스태미너·재고·메뉴·퀘스트 단계·주문·정산·저장 복구가 기록된다.
- UI 대상 미발견, 입력 후 예상 상태 미변화, Unity/브라우저 오류, 퀘스트 단계 역행은 실패다.
- 단순 부팅 smoke는 이 캠페인의 대체물이 아니다.

## 되돌리기

정책 공용 계약과 E2E 전용 bridge/driver만 제거하면 게임 런타임 규칙과 저장 포맷은 이전 상태로 돌아간다.
