## 핵심 문제 (이것부터 해결)

### 1. 코어 루프가 안 돌아감

기획서의 자원 순환: `골드 → 재료 구매 → 요리 → 판매 → 골드 (+텃밭 투자)`

현실: 시작 재료 99개 → 구매 불필요 → 텃밭 불필요 → 골드 쓸 곳 없음.
경제 순환의 "지출"이 통째로 빠져 루프가 아니라 일직선.

### 2. 제약이 없음

| 제약 (설계) | 현실 |
|------------|------|
| 스태미나 → 행동 제한 | 1/게임이라 무한 |
| 대기시간 → 시간 압박 | 180초라 안 떠남 |
| 유통기한 → 재고 관리 | 미구현 |
| 돈 → 구매력 제한 | Day 2에 무한 |
| 파산 → 실패 위험 | 체크 없음 |

제약 없는 게임 = 선택지 없는 게임.

### 3. 목표가 없음

승리/패배/마일스톤 전무. 플레이어가 왜 계속 해야 하는지 모름.

**이 3개가 해결되면 아래 세부 이슈의 밸런싱이 의미를 가짐.**
