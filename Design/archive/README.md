# Design/archive/

작성/편집 시점 이후 stale 처리된 문서 보관소.

**규칙:**
- 삭제 대신 여기로 이동. 이력/맥락 필요 시 복구 가능.
- 파일명 suffix로 원본 작성 일자 표기 (`_YYYY-MM-DD.md`).
- 파일 head에 `[ARCHIVED]` 마커 + 왜 stale인지 짧게 명기.

**현재 아카이브:**
- `balance-issues_2026-04-08.md` — 2026-05 대규모 리팩터 이전 밸런스 감사. 다수 항목 이후 해결됨 (파산/유통기한/관리비 등 최신 코드 재검증 필요).
