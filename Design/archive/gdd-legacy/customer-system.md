# 손님 시스템

한 페이즈의 영업이 시작되면 가게에 정해진 범위에서 랜덤한 주기로 손님이 방문한다.
해당 날의 판매 메뉴 중 1개의 도시락을 주문하며 주문 후 대기시간을 가진다.
대기시간 내 도시락이 완료되지 않으면 가게를 떠난다.

```
손님 입장 & 주문 → 요리 (대기시간) → 손님 반응
```

## 대기시간

모든 손님은 동일한 대기시간을 가진다.
작은 대기시간 바를 통해 표시.

## 유저 플로우

1. 영업이 시작되면 랜덤한 타이밍에 손님이 가게에 들어와 매대 앞으로 이동해 주문.
2. 당일 판매 메뉴 중 1개를 랜덤 선택하여 주문하고 주문 내용은 UI의 주문서를 통해 표시.
3. 요리하는 동안 대기시간이 줄어들고 도시락을 완성하여 포장하면 손님은 계산식에 따라 재화를 지불한다.

## 보상 산정

```
보상 = 총 가격 × 기본 배율 × 추가 배율
```

- **기본 배율**: 메인 메뉴가 주문과 일치하면 **1.0**, 불일치하면 **0.7**
- **추가 배율**: **1.0 + 주문과 일치한 사이드 메뉴의 갯수 × 0.1**

### 보상 예시

| 상황 | 기본배율 | 추가배율 | 최종 |
|------|---------|---------|------|
| 메인 일치 + 사이드 2개 일치 | ×1.0 | ×1.2 | ×1.20 |
| 메인 일치 + 사이드 0개 | ×1.0 | ×1.0 | ×1.00 |
| 메인 불일치 | ×0.7 | ×1.0 | ×0.70 |
