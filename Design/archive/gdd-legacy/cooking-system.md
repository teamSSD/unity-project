# 요리 시스템

보유한 재료 내에서 요리 도구를 활용해 요리(결과물)를 만드는 과정.
재료와 미니게임 점수에 따라 가격이 형성되며 레시피의 영향을 받는다.

```
재료 / 중간 재료 → 미니게임 (요리 도구) → 중간재료 / 요리
```

## 요리 도구

| 도구 | 미니게임 종류 |
|------|------------|
| 팬 | 굽기 |
| 냄비 | 끓이기 |
| 철판 | 익히기 |
| 도마 | 썰기 |
| 볼 | 소스 뿌리기, 섞기 |

## 도시락

사용자에게 판매할 수 있는 단위.
메인 요리 1개와 보조 요리(반찬 등) 0~3개로 구성된다.

## 레시피

요리를 만드는 과정이 담겨 있으며 중간 재료에 관한 정의도 포함된다.

## 가격 산정

```
가격 = Σ(재료의 가격 × (1 + 재료의 비중 × 점수))
```

- 점수는 미니게임의 점수이며 0~1의 범위를 가짐
- 가격은 중간 재료, 요리에 모두 계산됨

### 재료 비중 (weight) 체계

재료의 종류에 따라 비중이 달라진다.

| 분류 | 비중 (weight) | 대상 태그 |
|------|-------------|---------|
| 메인재료 | 1.50 | Grains, Meat, Seafood |
| 일반재료 | 1.30 | Vegetables, Dairy |
| 향신료/소스 | 1.00 | Sauces, Liquid, Other |
| 중간재료 (PROCESSING) | 0.20 | 이전 조리 결과물 |

### 재료 가격 체계

| 가격대 | 예시 |
|--------|------|
| 300G | 청양잎 |
| 600G | 인공고기, 물 |
| 1,500G | 흑미, 밀면, 두부 등 대부분 |
