# Core Loop

게임의 하루는 세 단계로 구성된다.

```
영업 준비 → 페이즈 진행 → 일별 평가
```

## 영업 준비

플레이어가 재료를 확보하고 판매할 메뉴를 정하는 단계.
텃밭 수확, 상점 구매 등을 할 수 있고 판매할 메뉴를 정해야 끝난다.
시간 제한 없음.

## 페이즈 진행

아침 / 점심 / 저녁 / 밤 으로 총 네 페이즈가 있다.
각 페이즈마다 플레이어는 세 행동 중 하나를 선택할 수 있다.
**단, 아침은 반드시 영업을 해야 한다.**

| 행동 | 설명 |
|------|------|
| 재료 수급 | 텃밭 수확, 상점 구매 등으로 재료를 얻을 수 있다. 재료에는 소비기한이 존재하며, 지날 경우 사라진다. |
| 영업 | 손님들이 동시다발적으로 방문. 손님들은 인내심(시간)을 가지며 만료될 경우 떠난다. 요리의 완성도와 손님 취향에 따라 재화를 획득. |
| 휴식 | 스태미너를 회복한다. |

## 배달

상가에서 배달 주문을 받을 수 있으며 이를 통해 스토리를 진행할 수 있다.
영업 시간에 주문한 도시락을 만들어 상가로 돌아가 전달한다.
배달 주문을 받을 때 일부 레시피가 해금된다.

## 일별 평가

당일 영업의 요약 정보를 제공한다.

## 자원 흐름

```
          판매
골드 ─골드→ 재료 ─요리과정→ 요리
       ↑                    │
       └────────────────────┘

골드 ─업그레이드→ 텃밭 ──→ 재료 (무료 공급)

스태미너 ─미니게임→ 요리
    ↑
   휴식
```

- 재료는 유통기한이 지나면 폐기
- 텃밭은 랜덤한 작물이 페이즈마다 자라며 일부 재료를 생산, 업그레이드를 통해 생산속도/양 증가

## 주요 재화

| 재화 | 용도 |
|------|------|
| 골드 | 상점 구매, 텃밭 업그레이드에 사용 |
| 스태미너 | 미니게임을 할 때마다 소비, 휴식으로 회복 |
