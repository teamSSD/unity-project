### 2-b. 퀘스트 시작 대화

<aside>
🗣️

노크 두 번.

가브리엘 : …누구야.
플레이어 : 배달이요.
가브리엘 : 배달이 이 시간에?
플레이어 : 주문하셨잖아요.
가브리엘 : …했나.

문이 열린다.

가브리엘 : 배달꾼 치고 눈이 맑네. 이 동네 오래 있으면 그것도 없어지는데.

플레이어 :

1. 오래 있을 생각은 없어요 — 배달 끝나면 가야 하니까요.
가브리엘 : 하, 그렇겠지. 들어와. 세워두기도 그러니까.
2. 익숙해지면 되죠 — 뭐든.
가브리엘 : 익숙해지는 게 다 좋은 건 아니야. 들어와.

가브리엘 : 뭐 가져왔어.
플레이어 : 기계장 고기정식이에요. 오래된 고기 손질해서 다시 절인 거예요.
가브리엘 : 오래된 걸 손질해서. 낭만 없는 이름이네.
플레이어 : 냄새 맡아봐요.
가브리엘 : (뚜껑 열며) …어. 냄새는 낭만 있네.
`(배달 수주)`

</aside>

### 2-c. 퀘스트 진행 중 대화

<aside>
🗣️

가브리엘 : 너 음악 들어?
플레이어 : 가끔요.
가브리엘 : 가끔. 좋은 대답이야. 항상 듣는다는 놈치고 제대로 듣는 놈 없거든.

플레이어 :

1. 가브리엘 씨는요? — 요즘도 들어요?
가브리엘 : 나는 요즘 안 들어. 들으면 손이 움직이거든. 그게 귀찮아서.
플레이어 : 손이 움직이면 왜 귀찮아요.
가브리엘 : 움직이면 뭔가 만들어야 할 것 같잖아. 만들면 들려줘야 할 것 같고. 들려주면… 수고스러워지거든.
2. 저 악보 다 쓴 거예요? — 벽에 붙은 거요.
가브리엘 : 옛날에. 지금은 그냥 벽지야.
플레이어 : 버리면 되잖아요.
가브리엘 : 버리면 진짜 벽지가 되잖아. 지금은 그래도 악보니까.

</aside>
<aside>
🗣️

가브리엘 : 옛날에 공연할 때— 맨 앞줄에 항상 같은 사람이 있었어. 매번 왔는데 한 번도 말 건 적 없어. 근데 그 사람 없는 날은 공연이 좀 달랐어.

플레이어 :

1. 어떻게 달랐어요? — 소리가 달라져요?
가브리엘 : 소리는 똑같았는데. …방향이 없었다고 해야 하나.
2. 지금도 그 사람 와요? — 아직 연락해요?
가브리엘 : 공연이 없는데 어떻게 와. 내가 없애버렸거든, 공연을.
플레이어 : 왜요.
가브리엘 : 뭐, 여러 가지.

</aside>

### 2-d. 퀘스트 완료 대화

<aside>
🗣️

접시가 거의 비워진다.

가브리엘 : 다 먹었다. …오랜만이네, 이렇게.
플레이어 : 원래 잘 안 드세요?
가브리엘 : 먹긴 먹어. 다 먹는 건 좀 달라. 다 먹으면 다음이 와버리거든.
플레이어 : 다음이요?
가브리엘 : 다음 끼니. 다음 날. 뭐, 그런 것들.

플레이어 :

1. 그게 싫어요? — 다음이 오는 게요.
가브리엘 : 싫다기보다— 좀 무게감이 있어. (잠깐 있다가) 근데 오늘은 뭐, 다음이 와도 될 것 같기도 하고.
플레이어 : 그럼 됐네요.
가브리엘 : …그러네.
2. 또 올게요 — 주문하면요.
가브리엘 : 어. (잠깐 있다가) 오늘은 뭐, 다음이 와도 될 것 같기도 하고.
플레이어 : 다음에 또 다 드세요.
가브리엘 : 봐가며.

플레이어 : 또 주문하면 올게요.
가브리엘 : 어. …노크 두 번 기억해.
플레이어 : 세 번 하면 안 열어준다고요.
가브리엘 : 두 번이랑 세 번 사이에 뭔가 있거든.
플레이어 : 뭔데요.
가브리엘 : 그건 두 번 했을 때 알 수 있지.

문이 닫힌다.
위에서 악보 넘기는 소리가 들린다.

</aside>

`— 다 먹으면 다음이 와버린다.
  오늘은 그래도 될 것 같기도 하고. —`
