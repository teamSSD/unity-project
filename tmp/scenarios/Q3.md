## 🌊 Episode: 새벽 네 시의 거래

### — 새벽풀은 빛을 오래 쬐면 향이 사라진다.

### 2-b. 퀘스트 시작 대화

<aside>
🗣️

니모 : 왔어, 왔어. 오늘 딱 맞지? 운하 안개 때문에 좀 돌아왔는데 그래도 4시 맞지?
플레이어 : 4시 1분.
니모 : 1분은 오차범위야. 아, 오늘 해초 상태 진짜 좋아— 냄새 맡아볼래?

플레이어 :

1. 괜찮아요 — 그냥 들여놓을게요.
니모 : 아, 맡아보면 달라니까, 진짜로. 뭐 어때. 나중에 써보면 알아.
2. 맡아볼게요 — 어디요?
니모 : 이쪽이야, 이쪽. 어때? 달리지? 운하 안쪽이랑 바깥쪽이랑 향이 달라서 내가 따로 골랐어.
플레이어 : …확실히 다르네요.
니모 : 그렇지? 그렇지!

니모 : 아, 이거— 새벽풀이야. 차광 포장 그대로 써. 빛 들어가면 향 날아가. 빨리 써야 해.
플레이어 : 잠깐만요, 국 끓이는 동안 있어요.
니모 : …어, 나?
플레이어 : 밥은 먹고 가야죠.
니모 : 아, 뭐— 그럼 짧게만. 오전 장 전에 루트 있거든.
`(배달 수주)`

</aside>

---

### 2-c. 퀘스트 진행 중 대화

<aside>
🗣️

닭뼈 육수가 끓기 시작한다.

니모 : 그나저나 나 이번 달에 수송선 업그레이드 알아보고 있어.
플레이어 : 지금 것도 얼마 안 됐잖아요.
니모 : 3년 됐어, 3년! 운하에서 3년이면 거의 노인이라고. 조만간 더 큰 수송선을 사고야 말테야.

플레이어 :

1. 돈은 있어요? — 수송선이 얼만데요.
니모 : 그걸 알면 이미 샀겠지. 지금 모으는 중이야. 외지구 루트 수수료가 좀 더 나오면 될 것 같은데— 슬럼 선적 이력 있으면 중고값 떨어지려나. 그게 걱정이야.
2. 지금 것도 잘 쓰던데 — 딱히 불편해 보이진 않았는데.
니모 : 내가 불편한 거야! 생선이 아니라. 좁은 데서 오래 있으면 피부가 더 빨리 말라. 장갑 두 겹 껴야 하거든, 요즘.

버섯가루가 들어가며 잡내가 잡힌다.

니모 : 저거 내가 고른 버섯가루 맞지?
플레이어 : 맞아요.
니모 : 좋아. 시장 거랑 건조 온도가 달라. 직접 말린 거거든.

</aside>
<aside>
🗣️

니모 : 자, 새벽풀— 진짜 빨리 써야 해.
플레이어 : 불 끌게요.
니모 : 넣기 전에 나 잠깐 맡아봐도 돼? 포장만. 열지 말고.
플레이어 : 왜요?
니모 : 향이 포장지 안쪽에 조금 배어있어. 오는 내내 옆에 있었거든. 그냥 궁금해서.

플레이어 :

1. 빨리 해요 — 불 끄기 전에.
니모 : 알아 알아, 잠깐만. 으음— 좋다. 됐어, 넣어.
2. 저도 궁금한데 — 어떤 냄새예요?
니모 : 음… 새벽 냄새야. 아직 아무것도 타지 않은 냄새? 설명이 이상한가. 그냥 맡아봐.
플레이어 : (맡아본다) …맞아요. 그 냄새네요.
니모 : 그렇지?

불을 끄고 새벽풀을 넣는다. 향이 확 퍼진다.
니모 : …오, 이거다.

</aside>

### 2-d. 퀘스트 완료 대화

<aside>
🗣️

새벽국이 완성된다. 두부가 올라간다.

플레이어 : 먹어요.
니모 : 나? 먹어도 돼?
플레이어 : 앉아요.
니모 : 고마워, 진짜로. 새벽에 운하 돌면 배가 진짜 고픈데 드론선엔 육포랑 캔 음료밖에 없거든. 조만간 거기도 가열 장치 달아야—
플레이어 : 먹으면서 말해요.
니모 : …

첫 숟가락.

니모 : 따뜻하다.

플레이어 :

1. 매일 이 시간에 오면서 — 밥은 어디서 먹어요, 보통.
니모 : 거의 못 먹어. 오전 장 끝나고 집 가면 그때 먹는데— 그게 점심이야, 사실. 아침이라고 부르기도 좀 그렇고.
플레이어 : 그럼 오늘 이게 첫 끼네요.
니모 : …그러네. 첫 끼. 그러네.
2. 오늘 새벽풀 상태 좋았어요 — 향이 달랐어요.
니모 : 그렇지? 내가 골랐으니까. 운하 안쪽 그늘에서 자란 거야. 빛이 거의 안 닿은 거라 향이 더 진해.
플레이어 : 그걸 어떻게 알아요.
니모 : 나 원래 그런 거 잘 찾아. 숨어있는 거.

니모 : 뭍에 있으면 다들 숨을 참는 것 같아. 나도 그런 것 같고. 근데 이거 먹으면— 잠깐 내려놓게 되는 것 같아.
플레이어 : 매일 새벽에 오는데, 몰랐어요.
니모 : 말 안 했으니까. 나 말 많은데 그런 말은 잘 안 해.

플레이어 :

1. 왜요? — 말하기 어려워요?
니모 : 어렵다기보다… 새벽풀이랑 비슷한 것 같아서. 오래 꺼내두면 사라질 것 같아서.
플레이어 : 사라지지 않아요.
니모 : …그럼 다음엔 좀 더 해볼게.
2. 그런 말도 해요 — 가끔은.
니모 : 그러면 돼?
플레이어 : 여기선요.
니모 : …알겠어. 기억해둘게.

니모 : (일어나며) 자, 나 이제 진짜 가야 해. 바쁘다 바빠. 다음 주엔 새벽풀 두 묶음 가져올게.
플레이어 : 두 묶음이요?
니모 : 하나는 빛에 두면 어떻게 되는지 실험용으로.
플레이어 : 재료 아깝다고요.
니모 : 내가 주는 거니까 괜찮아. 어떻게 사라지는지— 한번쯤 봐도 되잖아.

드론선 시동 소리.

니모 : (멀어지며) 다음 주 해초도 특급으로 가져올게. 진짜로 달라, 진짜로—

동쪽이 조금씩 밝아온다.

</aside>
