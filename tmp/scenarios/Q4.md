## 🕴️ Episode: 정장 입은 사람의 허기

### — 세련되지 않았지만, 묘하게 편안합니다.

### 2-b. 퀘스트 시작 대화

<aside>
🗣️

세라프 : 실례합니다. 자리 괜찮을까요?
플레이어 : 앉으세요.
세라프 : 채소 위주로 부탁드려도 될까요. 오늘은 무거운 게 별로라서요.

플레이어 :

1. 네온 샐러드 있어요 — 채소 위주면 딱 맞는 게 있어요.
세라프 : 좋습니다. 그걸로 할게요.
플레이어 : 잠깐 기다리세요.
`(배달 수주)`
2. 어떤 게 좋아요? — 조금 더 구체적으로 말해줘요.
세라프 : 가볍고, 향이 있는 걸로요. 오늘 냄새가 좀 많이 맡아서요.
플레이어 : 네온 샐러드면 될 것 같네요.
세라프 : 믿을게요.
`(배달 수주)`

</aside>

### 2-c. 퀘스트 진행 중 대화

<aside>
🗣️

루미잎과 채소를 섞으며 색 대비를 만든다.

세라프 : 여기 오는 게 벌써 세 번째인데, 메뉴판은 오늘 처음 보네요.
플레이어 : 그냥 달라는 대로 드렸거든요.
세라프 : 맞아요. 그게 편했어요.

플레이어 :

1. 이 근처에 일이 있어요? — 자주 보이던데.
세라프 : 출장이에요. 좀 길어지고 있어요.
플레이어 : 무슨 일이에요?
세라프 : 서류 일이에요. 재미없는 종류의.
2. 여기 음식이 입에 맞아요? — 외지구 분한테는 낯설 수 있는데.
세라프 : 세련되지 않았는데, 묘하게 편안합니다.
플레이어 : 세련된 데서 드시면 되잖아요.
세라프 : 그렇죠.

연두콩을 그을린다. 레몬드래스 드레싱. 마지막으로 전기꽃을 올린다.

플레이어 : 전기꽃이 들어가요. 금속 포크 쓰면 입안에 살짝 찌릿할 수 있어요.
세라프 : 괜찮습니다.

</aside>

### 2-d. 퀘스트 완료 대화

<aside>
🗣️

네온 샐러드가 나온다.

세라프가 한 입 베어 문다. 전기꽃이 씹힌다.

세라프 : …독특하네요.
플레이어 : 처음엔 다들 그래요.
세라프 : 읽었는데도 몰랐어요. 아는 것과 겪는 게 다른 경우가 있더라고요.

플레이어 :

1. 자주 있어요? — 그런 경우가요.
세라프 : 요즘 들어서는요.
플레이어 : 무슨 일이에요, 요즘.
세라프 : (웃으며) 서류 일이에요. 재미없는 종류의.
2. (아무 말 없이 다음 걸 준비한다) — …
세라프 : 디저트 있다고 하셨죠?
플레이어 : 루미 젤리요. 불 끄면 빛나요.
세라프 : 그거로 할게요.

루미 젤리가 나온다. 조명이 낮아지며 젤리가 희미하게 빛난다.
세라프가 젤리를 보며 잠깐 멈춘다.

플레이어 :

1. 왜요? — 마음에 안 들어요?
세라프 : 아니요. 그냥— 예쁘네요.
2. 조명시럽이에요 — 조명 벌레 분비액을 정제한 거예요.
세라프 : …그렇군요. (한 입 먹고) 맛있네요. 출처를 몰랐을 때랑 별로 다르지 않아요.
플레이어 : 그런 편이 나을 때도 있죠.
세라프 : 그렇죠. 그런 편이 나을 때가 있어요.

세라프가 계산을 하고 일어선다.
플레이어 : 많아요.
세라프 : 괜찮습니다. 다음에 또 와도 되죠?
플레이어 : 오세요.
세라프 : (문 앞에서 돌아보며) 여기 오래 할 거죠? 이 가게.
플레이어 : 그럴 생각이에요.
세라프 : 잘 됐네요. 진심으로요.

문이 닫힌다.

</aside>
