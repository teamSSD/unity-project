### 2-b. 퀘스트 시작 대화

<aside>
🗣️

레데 : 야, 나야 나! 거래 하나만 하자. 별거 아니야, 진짜로.
플레이어 : 또 별거 아닌 거래예요.
레데 : 야, 그건 지난번 얘기고! 이번엔 내가 희귀 향신료 루트 열어줄 테니까 삼각밥 하나만 해줘. 들고 다닐 수 있는 거로.

플레이어 :

1. 향신료 루트가 삼각밥이랑 교환이에요? — 좀 이상한 거래네요.
레데 : 뭐가 이상해? 나는 밥 필요하고 넌 재료 필요하잖아. 이게 거래지.
플레이어 : …지금 배고픈 거죠.
레데 : 거래 얘기 하는 거야, 지금.
`(배달 수주)`
2. 향신료 루트가 진짜예요? — 믿어도 돼요?
레데 : 야, 레데 마크 붙은 거야. 품질 보장이지. 외지구 통해서 들어오는 거라고.
플레이어 : 알겠어요, 삼각밥 할게요.
레데 : 그렇지! 거래 성립.
`(배달 수주)`

</aside>

### 2-c. 퀘스트 진행 중 대화

<aside>
🗣️

흑미밥을 편다. 절인 가지와 청양잎 절임을 속으로 넣는다.

레데 : 이거 흑미야? 밥이 이렇게 검어도 돼?
플레이어 : 먹어보면 알아요.
레데 : 이 빨간 거는 뭐야— 손 치워요, 알아 알아.

플레이어 :

1. 청양잎 절임이에요 — 속재료예요.
레데 : 향은 좋네. 매워?
플레이어 : 조금요.
레데 : 좋아. 나 매운 거 좋아하거든.
2. (말없이 계속 만든다) — …
레데 : 야, 물어봤잖아. 이거 뭐냐고.
플레이어 : 청양잎 절임이요.
레데 : 처음부터 말해주면 되잖아, 진짜.

잿빛 간장을 손으로 바르며 삼각형으로 쥔다.

레데 : 손으로 해? 도구 없어?
플레이어 : 손이 도구예요.
레데 : 멋있는 척하지 마.

신문지 포일로 삼각밥을 싼다.

레데 : 야, 그거 신문지야?
플레이어 : 폐쇄된 인쇄소에서 나온 포일이에요.
레데 : …C구역 거?
플레이어 : 거기서 구했어요.
레데 : 아, 그래? 나도 거기 자주 갔거든. 종이 냄새 좋잖아. 옛날에.

</aside>

### 2-d. 퀘스트 완료 대화

<aside>
🗣️

포일에 싼 삼각밥을 철판에 올린다. 표면이 바삭하게 굳는다.

레데 : 오, 소리 난다. 이거 진짜 먹는 거 맞아?
플레이어 : 식기 전에 먹어요.

레데가 삼각밥을 받는다. 포일을 잡는 순간 코를 킁거린다.

레데 : …이 냄새. 인쇄소 냄새랑 비슷해.

한 입 베어 문다.

레데 : 야. 맛있다, 이거.

플레이어 :

1. 다행이네요 — 거래 조건 맞죠?
레데 : 어. 내가 손해 본 거 아닌데? 향신료 루트 다음에 진짜 연락 줄게.
플레이어 : 다음에요?
레데 : 어, 왜. 지금 당장 해야 해?
2. 포일 냄새요? — 인쇄소를 자주 갔어요?
레데 : 뭐— 그냥. 예전에. 그냥 자주 갔어.
플레이어 : 왜요?
레데 : 야, 삼각밥 먹으면서 그런 거 물어보면 돼?

삼각밥을 다 먹는다. 레데는 자리에서 일어나지 않는다.

플레이어 : 거래 끝났잖아요.
레데 : 어. …아직 소화 중이야.
플레이어 : 빠른 사람이 소화가 느리네요.
레데 : 나 원래 그래. 먹고 나면 좀 있어야 해.

플레이어 :

1. 포일 더 필요하면 — C구역 루트 아직 살아있어요?
레데 : 어, 살아있지. 내가 구해다 줄 수 있어. 그것도 거래야, 물론.
플레이어 : 물론이죠.
레데 : 그렇지. 이제 좀 아네.
2. 인쇄소 자주 갔다고 했잖아요 — 거기서 뭐 했어요?
레데 : 야, 그냥. 뭐, 냄새가 좋았다고. 거기 있으면 아무도 안 찾아오거든.
플레이어 : 혼자 있고 싶었던 거예요?
레데 : …거래 얘기 하자, 우리.

레데가 일어나며 문 쪽으로 걷다가 멈춘다.

레데 : 근데 맛있었어. 진짜로. 포일 냄새가 좋았어.
플레이어 : 또 오면 되잖아요.
레데 : 거래 있을 때.
플레이어 : 그래요.
레데 : (나가며) …뭐, 거래야 만들면 되지.

</aside>

`— 거래 하나만, 딱 하나만.
  근데 소화가 좀 느려서. —`
