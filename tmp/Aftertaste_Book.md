### 3. 하루의 흐름 (Core Loop)

**전체 사이클**
영업 준비 → 페이즈 진행(아침/점심/저녁/밤) → 일별 평가

하루는 **5개의 페이즈**로 구성된다.

| 페이즈 | 시간대 (게임 내) | 비고 |
|---|---|---|
| 영업 준비 (Preparation) | 5:00 ~ 7:00 | 하루의 시작 |
| 아침 (Morning) | 7:00 ~ 12:00 | |
| 점심 (Afternoon) | 12:00 ~ 17:00 | |
| 저녁 (Evening) | 17:00 ~ 22:00 | |
| 밤 (Night) | 22:00 ~ 다음날 5:00 | 페이즈 종료 후 일별 평가 |

**각 페이즈에서 선택 가능한 행동 (3종)**

| 행동 | 효과 | 이동 씬 |
|---|---|---|
| **영업 (Work)** | 손님을 받고 요리를 판매한다 | Cooking |
| **상가 이동 (Shopping)** | 상점에서 재료를 사고, 텃밭에서 작물을 수확한다 | Mall → Shop / Garden |
| **휴식 (Rest)** | 스테미너 +60 회복 | 즉시 |

> 디자인 의도: 아침 페이즈는 영업 전용. 현재 빌드는 디버깅 편의를 위해 모든 페이즈에서 자유 선택을 허용하고 있다.

스테미너는 다음 날 시작 시 100으로 리셋된다.

**일별 평가 (Settlement)**
밤 페이즈 종료 후 정산 화면을 보여준다.

- **수입**: 페이즈별 매출 (아침/점심/저녁/밤)
- **지출**: 재료 구매, 업그레이드(텃밭/도구/저장공간), 관리비(고정 1,000G)
- **순익**: 수입 − 지출
- **잔액**: 최종 보유 금액

### 4. 요리 시스템

**시스템 요약**
보유한 재료 내에서 요리 도구를 활용해 요리(결과물)를 만드는 과정. 재료와 미니게임 점수에 따라 가격이 형성되며 레시피의 영향을 받는다.

**흐름**
재료 / 중간 재료 → 미니게임 (요리 도구) → 중간 재료 / 요리

**요리 도구 5종 / 미니게임 6종**

| 도구 ID | 도구 | 미니게임 ID | 미니게임 | 구현 클래스 |
|---|---|---|---|---|
| T001 | 팬 | M001 | 굽기 | FireMiniGame |
| T002 | 냄비 | M002 | 끓이기 | ClickMiniGame |
| T003 | 보울 | M004 | 소스 뿌리기 | SauceMiniGame |
| T003 | 보울 | M005 | 섞기 | MixMiniGame |
| T004 | 도마 | M006 | 썰기 | SliceMiniGame |
| T005 | 철판 | M007 | 익히기 | GriddleMinigame |

각 도구 일러스트는 placeholder 자리 필요.

**도시락**
사용자에게 판매할 수 있는 단위. 메인 요리 1개와 보조 요리(반찬 등) 0~3개로 구성된다.

**레시피**
요리를 만드는 과정이 담겨 있으며, 중간 재료에 관한 정의도 포함된다.
레시피는 입력 재료 목록 → 미니게임(도구) → 출력 음식의 구조이며, 출력 음식이 다시 다른 레시피의 입력이 될 수 있다 (체인).

**가격 산정 공식**
```
요리 가격 = Σ(재료의 가격 × (0.85 + 재료의 비중 × 미니게임 점수))
※ 미니게임 점수는 0~1 범위
※ 가격은 중간 재료와 최종 요리에 모두 계산됨

체인 보너스 (메인/사이드 음식 대상):
최종 가격 = 기본 가격 × (1.0 + 0.15 × (체인 깊이 - 1))
※ 체인 깊이: 해당 음식을 만들기까지 거친 레시피 단계 수
```

### 5. 손님과 배달

**손님 (영업)**
손님들은 동시다발적으로 방문한다. 각자 인내심(시간)을 가지며 만료되면 떠난다. 도시락의 정확도와 손님 취향에 따라 재화를 획득한다.

**메뉴 정확도 점수 (0.0 ~ 1.0)**
```
정확도 = 메인 점수(0.6) + 사이드 점수(0.4)

메인 점수:
- 주문과 일치: 0.6
- 불일치: 0.0

사이드 점수:
- 완벽 (요청한 사이드 모두 + 추가 없음): 0.4
- 부분 일치: (일치 비율 × 0.4) - (추가 사이드 수 × 0.1)
- 최저 0.0, 최고 0.4
```

주문 충족 판정: 메인이 일치하고 (요청 사이드가 없거나 일부라도 일치) → 유효 주문.

**영업 보상 공식**
```
보상 = 총 가격 × 메인 배율 × 사이드 배율
※ 메인 배율: 메인 메뉴가 주문과 일치하면 1.0, 불일치하면 0.7
※ 사이드 배율: 1.0 + (주문과 일치한 사이드 메뉴 갯수 × 0.05)
```

**배달**
상가에서 배달 주문을 받을 수 있으며 이를 통해 스토리를 진행할 수 있다. 영업 시간에 주문한 도시락을 만들어 상가로 돌아가 전달한다. 배달 주문을 받을 때 일부 레시피가 해금된다.

배달 NPC는 **단계 진행 시스템 (DeliveryQuestStage)** 을 가지며, 각 단계는 선행조건(이전 단계 완료, 특정 일자 도달 등)을 만족해야 활성화된다. 대화는 단계별로 분기되어 스토리가 점진적으로 펼쳐진다.

**배달의 의미**
- 스토리 진행
- 레시피 해금
- 특수 NPC와의 만남

### 6. 텃밭 & 상점 (가게 성장)

**텃밭**
플레이어의 채소·과일 종류 작물의 수급처. 별도의 재배 과정이 필요하지 않으며 수확 이후에 자동으로 새로운 무작위 작물이 자란다.

- 작물마다 자라는 데 필요한 페이즈 수가 다름 (`growPhaseCount`)
- 작물은 상하지 않으며 수확 시기는 정해져 있지 않음
- **텃밭 업그레이드**로 작물 성장에 필요한 페이즈 수를 단축할 수 있음 (`timeReduction`)
- 작물 데이터는 CSV 테이블 (`CropData`) 로 정의

**상점**
플레이어의 재료 수급처이자 재화 소비처.

- **기본 재료**: 매일 고정 진열 (밀가루, 쌀, 물 등)
- **특별 재료**: 매일 무작위로 일부 선정되어 진열

**상점 제약**
- 판매 수량 늘리기 불가능
- 가격 낮추기 불가능
- 유통기한은 재료의 고정값으로 존재

**재료 소비기한**
- 각 재료(FoodData.ingredient)에는 `expirationDay` 값이 존재 (기본 10일)
- 구매/획득 시점부터 **일 단위**로 카운트다운
- 0일이 되면 인벤토리에서 자동 제거
- 인벤토리는 FIFO (먼저 구매한 재료부터 사용)

### 7. 스토리 샘플

게임 내 스토리는 **상가 배달 NPC와의 대화**를 통해 점진적으로 전개된다. 각 NPC(또는 NPC 페어)는 **다섯 단계의 대화**를 가지며, 플레이어가 배달 의뢰를 받고 완수할 때마다 한 단계씩 진행된다.

**대화 단계 (DeliveryQuestStage)**

| 단계 | 의미 |
|---|---|
| FirstMeet | 첫 만남 |
| Normal | 평시 대화 |
| QuestStart | 배달 의뢰 시작 |
| Ordering | 의뢰 진행 중 (도시락 제작 대기) |
| OrderEnd | 의뢰 완료 후 반응 |
| Completed | 모든 단계 완료 (별도 대화 없음) |

선행 그룹 의존성(`prerequisiteGroupId`) 에 따른 해금 순서:
**전력실 페어 → 야시장 → 니모 → 세라프 → 레데 → 가브리엘**

#### 7-1. 전력실 페어 — 자르 & 게토로

- 플레이어: 위로가 되는 수치는 아니네요.
- 자르: 여기선 배보다 전기가 먼저 고장 나지.
- 플레이어: 그래서 배달이 필요한 거겠죠.

**평시**
- 자르: 겁먹은 표정인데, 괜찮겠어?
  - (선택 A) 괜찮아요. 이런 곳도 일이니까요.
    - 자르: 하, 마음에 드는군. 배달꾼답네.

#### 7-2. 야시장 — 파자마 & 모아이 & 스라냐

**첫 만남**
- 파자마: 어, 처음 보는 분이네요. 야시장에 오셨어요?
- 플레이어: 지나가다 들렀어요.
- 모아이: 으흠— 여기 자주 오면 좋아. 공기가 다르거든.

**평시**
- 파자마: 오늘도 잘 됐어요? 부스 쪽에서 냄새 좋던데요.
- 모아이: 으흠— 오늘도 온도 좋아.

**의뢰 시작**
- 파자마: 오늘 하늘은… 연기잎 버터 색이네요.
- 플레이어: 그게 무슨 색이에요?
- 파자마: 불 붙이기 직전에 잠깐 있는 색이요. 타지도 않고, 꺼지지도 않은.
- 모아이: 재료 배달 완료. 청유, 황동소금, 달의 뿌리— 전부 있어. 으흠.
- 파자마: 부스, 오늘 열 거죠?
  - (선택 A) 열어요. 야시장이잖아요. 당연히 열어야죠.
    - 파자마: 그럼 저는 옆에서 찍을게요. 도시락도 같이요.

### G. 레시피 데이터 전체 (31종)

입력 표기: `재료 이름 ×비중`. 비중은 가격 산정 공식의 `재료 비중`으로 사용된다. 비중 0.20은 중간 가공물(이미 비중이 누적된 재료)을 의미한다.

| 결과물 | 미니게임 | 입력 |
|---|---|---|
| 음식물쓰레기 | — | (없음, 실패물) |
| 해초 육수 | 끓이기 | 절인 해초 ×1.5 / 절연 버섯 ×1.3 / 물 ×1.0 |
| 새벽국 베이스 | 끓이기 | 해초 육수 ×0.2 / 새벽풀 ×1.3 |
| **새벽국** *(메인)* | 끓이기 | 새벽국 베이스 ×0.2 / 두부 ×1.5 |
| 삶은 밀면 | 끓이기 | 밀면 ×1.5 / 물 ×1.0 |
| 다진 절연 버섯 | 썰기 | 절연 버섯 ×1.3 |
| 다크소이 | 소스 뿌리기 | 다진 절연 버섯 ×0.2 / 오징어먹물 ×1.5 |
